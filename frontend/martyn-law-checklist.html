Venue Readiness Checklist

A practical checklist to help venue operators ensure access controls, staff procedures, and audit systems are in place — aligned to Martyn's Law readiness principles. Use it before, during, and after each event.

Important: This checklist supports operational readiness and helps you document security procedures. It is not legal advice and does not constitute a formal compliance assessment. Consult your legal team or a specialist adviser for guidance on your specific obligations under Martyn's Law.

Before the Event — Setup & Planning

Pre-event
Define entry points and assign staff to each Confirm how many entry points will be active and which staff members are responsible for each. Document this before the event day.
Configure Entri for the event Set up the event in Entri, add all entry points, and ensure the event code is active and verified. Entri supported
Brief all entry-point staff on the entry workflow Walk through the step-by-step procedure — identity check, Entri scan, and what to do if access is denied. Ensure all staff understand the escalation process.
Test the Entri system end-to-end Run a test scan at each entry point. Confirm that access logs are generating correctly and the organizer dashboard is live. Entri supported
Confirm backup entry procedure Document and communicate the manual fallback process in case of system or device failure. Ensure staff know the procedure without relying on technology.
Review capacity limits and restricted areas Confirm the total capacity for each zone, and ensure any restricted areas are clearly defined and assigned to responsible staff.
Document emergency evacuation procedures Ensure all staff have a copy of the evacuation plan and can locate all emergency exits. This is a core Martyn's Law requirement.
🚀

On the Day — Pre-Doors Check

Event day
Confirm all staff are at their assigned positions Do a roll-call before doors open. Identify any gaps and reassign staff as needed before the first attendee arrives.
Activate Entri at all entry points Confirm the Entri system is live, connected, and logging at every active entrance. Check the organizer dashboard shows all entry points active. Entri supported
Run a final device and connectivity check Test each device at each entry point. Confirm connectivity, camera access, and that QR code scanning is working.
Confirm communication channels are open Ensure all entry-point staff can reach the event controller (radio, phone, or messaging app). Test before doors open.
🎯

During the Event — Live Monitoring

Live
Monitor entry logs in real time via the organizer dashboard Keep the dashboard open and watch for any access denials, unusual patterns, or entry points going offline. Entri supported
Log any access incidents immediately If an attendee is denied entry, ejected, or an incident occurs at an entry point, record the time, location, and description. Entri access logs provide the identity trail. Entri supported
Ensure staff maintain their positions throughout the event Confirm that no entry point is left unattended while the event is live. If a staff member must leave, arrange a replacement first.
Track current attendance against capacity Use the Entri dashboard to monitor total attendees admitted. Flag if capacity is approaching limits. Entri supported
📊

After the Event — Audit & Review

Post-event
Download the full access log and attendance report Export the event report from the Entri organizer dashboard immediately after the event. Store it securely with your event records. Entri supported
Review any access incidents or denials Go through the log and identify any denied-access events. Document the outcome and any follow-up actions taken. Entri supported
Hold a brief debrief with entry-point staff Ask staff for feedback on the workflow, any pain points, and suggestions for improvement. Document key takeaways.
Archive the audit trail and event documentation Store the Entri access log, staff briefing notes, incident records, and any other event documentation in your compliance archive. Entri supported
Update procedures based on lessons learned If the debrief or audit log revealed gaps, update your entry workflow documentation before the next event.
