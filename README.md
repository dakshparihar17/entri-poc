# 🎟️ Entri — Identity. Simplified.

**Entri** is a next-generation identity and access platform designed for the Gen-Z era.  
We’re reimagining how people enter events, venues, and digital spaces — where **you are the ticket**.

Built for **events, nightclubs, and stadiums**, Entri combines **blockchain-backed identity**, **AI verification**, and **frictionless access control** to create a safer, smarter, and more exciting experience for both users and organizers.

---

## 🚀 Vision

> To make identity effortless and secure — online or offline.  
> From tickets to airports to age verification, Entri aims to unify access into one seamless identity system.

---

## 🧠 Features

- 🪪 **Smart Identity Layer** — Every user is uniquely verified on-chain for authenticity.  
- 🎫 **Blockchain-Backed Tickets** — Each ticket is immutable and uniquely tied to its holder.  
- 🔐 **Passwordless Access** — “You are the password.”  
- 🧩 **Organizer Dashboard** — Real-time analytics, crowd insights, and fraud prevention.  
- 🌍 **Scalable Infrastructure** — API-first design with modular microservices for easy integration.

---

## 🏗️ Tech Stack

| Layer               | Technology |
|---------------------|-------------|
| **Frontend**        | React (Vite / Next.js) + Tailwind CSS |
| **Backend**         | FastAPI (Python) / Node.js |
| **Database**        | MongoDB Atlas / PostgreSQL (via Supabase) |
| **Auth & Identity** | Blockchain ID + OAuth 2.0 |
| **Hosting**         | Frontend on Vercel, Backend on Render |
| **Version Control** | GitHub |
